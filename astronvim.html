Your config at ~/.config/nvim is the unchanged AstroNvim template: every file in lua/plugins/ starts with a line that turns it off. To add your own mappings, delete the first line of lua/plugins/astrocore.lua and edit its mappings table. These keys are for v4; AstroNvim v5 replaced Telescope and some others, so a few keys change if you upgrade.
