Copy mode scroll & select

prefixEnterEnter copy mode oh-my-tmux
prefix[Enter copy mode (standard)
mouse wheelScroll up; enters copy mode by itself
↑↓ PgUpPgDnMove and scroll
CtrlSpaceStart selecting
AltwCopy the selection to the tmux buffer
Ctrls / CtrlrSearch down / up
q or EscLeave copy mode
mouse dragSelect and copy. Hold Shift while dragging to use the terminal's own selection instead
These are emacs-style keys, because your config doesn't turn on vi mode. To use v to select, Ctrlv for a block and y to copy, uncomment set -g mode-keys vi at line 348 of ~/.tmux.conf.local. Copying stays inside tmux; set tmux_conf_copy_to_os_clipboard=true to also copy to the desktop clipboard.
