Vim 9.1 with no ~/.vimrc, so it uses Vim's built-in defaults. Everything here also works in Neovim and AstroNvim.

Esc back to Normal mode, always safe
:q! quit without saving
Ctrld hold Ctrl, press d :w type it, then Enter not in your vim feature missing

Modes

i aInsert before / after the cursor
I AInsert at start / end of the line
o OOpen a new line below / above
vVisual: select characters
VVisual line: select whole lines
CtrlvVisual block: select a rectangle
RReplace mode: overtype
:Command line
Esc or Ctrl[Back to Normal mode

Move

hjklLeft / down / up / right
w b eNext word start / previous word start / word end
W B ESame, but words are separated only by spaces
0 ^ $Line start / first non-blank / line end
gg GFirst / last line
42G or :42Go to line 42
fx txJump onto / just before the next x on the line
Fx TxSame, backwards
; ,Repeat the last f/t forwards / backwards
%Jump to the matching bracket
{ }Previous / next blank line (paragraph)
H M LTop / middle / bottom of the screen
Ctrld / uHalf a page down / up
Ctrlf / bA full page down / up
zz zt zbScroll so the cursor line is centred / at top / at bottom
Ctrlo / iJump back / forward through where you've been
gdGo to where the word under the cursor is defined (local)

Edit

xDelete the character
rxReplace the character with x
ddDelete (cut) the line
D CDelete / change to the end of the line
cc SChange the whole line
yyCopy (yank) the line
p PPaste after / before the cursor
uUndo
CtrlrRedo
.Repeat the last change
JJoin the next line onto this one
>> <<Indent / unindent the line
~Swap upper/lower case of the character
Ctrla / xAdd / subtract 1 from the number under the cursor
xp ddpSwap two characters / two lines

Operator + motion the grammar

d c yDelete / change / yank, followed by any motion or text object
> < =Indent / unindent / auto-indent
gU guMake upper / lower case
dw d3wDelete a word / three words
dt)Delete up to the next )
ciwChange the word under the cursor
ci" ca"Change inside quotes / including the quotes
di( da{Delete inside ( ) / around { } including braces
citChange inside an HTML/XML tag
yap dapYank / delete the paragraph
>ipIndent the paragraph
gUiwUpper-case the word
gg=GRe-indent the whole file
Text objects: i means inside, a means around. Then w word, s sentence, p paragraph, " ' ` quotes, ( [ { < brackets, t tag.

Visual mode after v, V or Ctrl-v

oJump to the other end of the selection
d y cDelete / yank / change the selection
> <Indent / unindent the selection
U u ~Upper / lower / swap case
JJoin the selected lines
gvSelect the last selection again (from Normal mode)
Ctrlv … I text EscInsert the same text at the start of every selected line
Ctrlv … $A text EscAppend the same text to every selected line

Search & replace

/text ?textSearch forwards / backwards
n NNext / previous match
* #Search for the word under the cursor, forwards / backwards
:nohClear search highlighting
:s/old/new/Replace the first match on this line
:%s/old/new/gReplace everywhere in the file
:%s/old/new/gcReplace everywhere, asking each time (y/n/a/q)
:'<,'>s/old/new/gReplace inside the selection (press : in Visual mode)
:g/pattern/dDelete every line that matches
:v/pattern/dDelete every line that doesn't match
\c in a searchIgnore case for that search, e.g. /error\c

Files & quitting

:wSave
:wq :x ZZSave and quit
:qQuit (refuses if there are unsaved changes)
:q! ZQQuit and throw away changes
:qaQuit every window
:e fileOpen a file
:e!Reload the file, discarding changes
:w other.txtSave a copy under another name
:r fileInsert another file below the cursor
:r !cmdInsert the output of a shell command
:w !sudo tee %Save a file you opened without permission
:ExBrowse files in the current folder (netrw)

Buffers, windows & tabs

:lsList open files (buffers)
:bn :bpNext / previous buffer
:b nameSwitch to a buffer by part of its name (Tab completes)
:bdClose the buffer
Ctrl^Switch to the previous file
Ctrlw s / vSplit top/bottom / left/right (or :sp :vs)
Ctrlw hjklMove to the window left / down / up / right
Ctrlw wGo to the next window
Ctrlw q / oClose this window / close all the others
Ctrlw =Make all windows the same size
Ctrlw _ / |Make this window as tall / wide as possible
:tabnewOpen a new tab
gt gTNext / previous tab
:tabcloseClose the tab

Registers, macros & marks

"ayyYank the line into register a
"apPaste from register a
"0pPaste the last yank, even after deleting something
"+y / pCopy to / paste from the desktop clipboard not in your vim
:regShow what's in every register
qa … qRecord a macro into a, then stop
@aPlay macro a
@@ 10@aPlay the last macro again / play a ten times
maSet mark a here (A–Z work across files)
'a `aJump to mark a's line / exact spot
`.Jump to the last change
''Jump back to where you were before the last jump
Your vim is built without clipboard support. Copy with the mouse, use Neovim, or install the vim-gtk3 package to get it.

Insert mode

CtrlwDelete the word before the cursor
CtrluDelete back to the start of the line
Ctrln / pComplete the word from the open files
Ctrlr"Paste the last yank without leaving Insert mode
CtrloRun one Normal-mode command, then return
Ctrlt / dIndent / unindent the line
Ctrlv TabInsert a real Tab or other special key literally

Folds, help & settings

zfmotionCreate a fold, e.g. zfap
zo zc zaOpen / close / toggle a fold
zR zMOpen / close every fold
:help wordHelp on anything, e.g. :help ciw, :help ctrl-w
Ctrl] / CtrloFollow a link in help / go back
:set nu :set rnuLine numbers / relative line numbers (nonu to turn off)
:set pastePaste from the terminal without auto-indent mess
:set icIgnore case in searches
:syntax onTurn on syntax colours
vimtutorA 30-minute interactive lesson (run it in the shell)
